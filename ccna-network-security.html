Project 02

CCNA Network Setup & Security Lab

A hands-on networking and security laboratory project focused on installing, configuring, segmenting, and protecting an enterprise-style environment.

Project overview

The project included the installation and configuration of routers, switches, and a FortiGate firewall. It applied network segmentation, access control, and security policies while maintaining system stability across Windows Server and Red Hat Linux environments.

Key activities

  • Router and switch installation
  • Network segmentation
  • Access control implementation
  • FortiGate firewall configuration
  • Security policy configuration
  • Windows Server and Red Hat Linux administration

Security focus

Designed the lab around controlled access, segmented network traffic, firewall enforcement, and stable infrastructure operations.

Technology stack

  • Routers
  • Switches
  • FortiGate
  • Windows Server
  • Red Hat Linux
