Project 01

Creative Digital CV

A web-based platform designed to generate ATS-compliant CVs, connect users with relevant opportunities, and provide personalized career recommendations.

Project overview

The platform helps users create structured CVs that are easier for applicant tracking systems to read. It integrates LinkedIn APIs for real-time job matching and uses an AI-driven recommendation engine to suggest certifications and courses based on each user's profile.

Key features

  • ATS-compliant CV generation
  • LinkedIn API integration
  • Real-time job matching
  • Personalized certification recommendations
  • Machine-learning-assisted results

My contribution

Led the project team and designed and developed the web platform structure. I connected the application flow to the database and contributed to the recommendation and job-matching experience.

Technology stack

  • PHP
  • MySQL
  • JavaScript
  • Machine Learning
